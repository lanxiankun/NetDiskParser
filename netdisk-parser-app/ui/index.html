夸克等网盘线程越多越快（建议 16~32）；123网盘走节点建议调低（4~8），连接少更可能全部走手机节点满速

使用说明
  1. 获取解析 API Key：前往 189.qaiu.top 注册账号，在用户面板复制 API Key 填入设置。
  2. 下载引擎已内置：Gopeed 下载引擎已集成在本 App 中，随 App 启动自动运行，无需单独安装或配置。下载目录可在设置中修改，保存后立即生效。
  3. 解析：粘贴网盘分享链接（支持蓝奏云、夸克、UC、天翼云盘、移动/联通云盘、123 盘等 20+ 平台），有提取码一并填入，点击「解析」。
  4. 下载：单文件可直接发送到下载；目录链接会展示文件树，可勾选多个文件后批量下载。内置引擎自动多线程下载并支持断点续传。
  5. 防盗链：奶牛快传、小飞机盘等平台需要附加请求头才能下载，本工具解析时自动获取并透传给下载引擎。
  6. 额度：每次成功解析消耗 1 次额度（缓存命中同样消耗）；链接详情与目录列表免费，可用于预检。
