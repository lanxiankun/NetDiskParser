Gopeed 与浏览器同一设备时填 http://localhost:9999（推荐）；手机端需在手机安装 Gopeed 后同填。Token 在 Gopeed Web 界面「设置 → 远程控制」中配置。

使用说明
  1. 获取解析 API Key：前往 189.qaiu.top 注册账号，在用户面板复制 API Key 填入设置。
  2. 安装并启动 Gopeed：从 Gopeed 官网下载对应平台版本（Windows / macOS / Linux / Android）。启动后在 Web 界面「设置 → 远程控制」中设置访问 Token。
  3. 解析：粘贴网盘分享链接（支持蓝奏云、夸克、UC、天翼云盘、移动/联通云盘、123 盘等 20+ 平台），有提取码一并填入，点击「解析」。
  4. 下载：单文件可直接发送到 Gopeed；目录链接会展示文件树，可勾选多个文件后批量下载。Gopeed 将自动多线程下载并支持断点续传。
  5. 防盗链：奶牛快传、小飞机盘等平台需要附加请求头才能下载，本工具解析时自动获取并透传给 Gopeed。
  6. 额度：每次成功解析消耗 1 次额度（缓存命中同样消耗）；链接详情与目录列表免费，可用于预检。
